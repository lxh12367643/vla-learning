## 关于 VLA基础.md

这份笔记记录的是一个**教学用的简化版** VLA：

- 数据是代码合成的（白底 + 红方块 + 蓝末端），不是真实机械臂数据
- 视觉塔用的是 CNN，真实 VLA 通常用 ViT / SigLIP
- 语言侧用词袋 + hash，真实系统用 LLM 或 BERT

它的价值不在模型本身，而在于把「数据 → 模型 → 训练 → 推理」这条链路自己走了一遍，并回答了 26 个「为什么这么设计」的问题（为什么用 h5 不用 csv、为什么取 T 帧历史、为什么用 L1 而不是 MSE、为什么要梯度裁剪……）。
